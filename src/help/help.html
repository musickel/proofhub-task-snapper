QUICK START GUIDE

Capture issues. Create ProofHub tasks.

Use ProofHub Task Snapper to capture an actual screenshot, optionally capture an expected page screenshot, and create a task or subtask directly in ProofHub.

1. Set up 2. Capture screenshots 3. Create a task 4. Annotation tools 5. Troubleshooting

1 Set up the extension

  1. Open the extension popup and select Settings & Task Lists.
  2. Enter your ProofHub API key in the password field.
  3. Add a Task List URL to create tasks, or a Task URL to create subtasks.
  4. Select your preferred light or dark theme.
  5. Save all settings. The popup and capture screens will follow your selected theme.

2 Capture screenshots

  1. Open the webpage you want to capture and select the target task or task list in the popup.
  2. Select Capture Actual (1/2), or use the configured keyboard shortcut.
  3. Select and crop the area you want to capture. Annotate it if needed, then confirm the screenshot.
  4. Navigate to the expected page if it is different, or stay on the current page.
  5. Select Capture Expected (2/2). Expected screenshots can be skipped when no expected page is needed.

3 Create a task or subtask

  1. After the screenshots are ready, the task details popup opens automatically.
  2. Enter a title and optional description.
  3. Select the destination task list or parent task.
  4. Complete any additional ProofHub fields shown for the selected destination.
  5. Select Add Task or Add Subtask. Use the × button at the top to close and cancel.
Note: The task description includes the actual screenshot and expected screenshot when captured. The displayed Page URL is the URL from the actual screenshot page.

4 Annotation tools

Highlight

Mark an area with a semi-transparent highlight.

Rectangle

Draw a rectangular outline around an issue.

Arrow

Point directly to the area that needs attention.

Text

Add a text note over the screenshot.

Color

Change the annotation color.

Undo / Reset

Remove annotations or start the crop again.

5 Troubleshooting

  • Capture does not start: Open a regular website instead of a browser settings, extension, or blank page.
  • API key rejected: Verify the key and confirm it is entered in extension Settings.
  • No destination shown: Add and save a valid ProofHub Task List or Task URL.
  • Shortcuts conflict: Configure a new shortcut in Settings. It must include Ctrl, Alt, or Cmd.
  • Dark mode missing: Save Dark Theme in Settings, then reopen the popup or capture screen.
